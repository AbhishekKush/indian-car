# Indian Car Images Dataset

High-quality vehicle thumbnail and exterior images dataset for Indian market cars across various brands, models, and variants.

## Structure

```
.
└── images/
    ├── <car-id>.[jpg|jpeg|png|webp]
    └── ...
```

## Total Assets
- **Total Images:** 5,115
- **Formats:** JPG, JPEG, PNG, WEBP
- **Naming Scheme:** Deterministic slug ID matching vehicle specifications (`<brand>-<model>-<variant>-<fuelType>-<transmission>.<ext>`)
